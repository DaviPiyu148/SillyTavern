# ADR-007: Character Growth Must Be Causal and Persistent

## Status

Accepted

## Decision

Characters can change over time, but persistent psychological changes should be grounded in experiences, interpretations, repeated pressures, relationships, goals, and circumstances.

## Reason

The product aims to simulate living characters rather than static prompt templates. Arbitrary LLM personality shifts would destroy continuity and user trust.

## Consequences

Character development needs persistent state and development history. Numerical traits may be used internally, but the model must also retain narrative causes and evidence.
